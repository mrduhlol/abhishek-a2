# Project content evidence

Reviewed on 2026-10-23 against each project's public GitHub README and repository metadata. `src/data/projects.js` contains short paraphrases, not promised performance outcomes. Terrain names and taglines are portfolio storytelling, not product capabilities.

All `live` fields intentionally remain `null`: the user will supply the subdomain destinations. Repository links are source-code links, and should not be presented as live product websites.

| Project | Primary evidence | Confirmed scope / caveats |
| --- | --- | --- |
| Orbit | [README](https://github.com/mrduhlol/Orbit#readme) | Local radial conversion for Omarchy / Hyprland, Python and GTK 4; FFmpeg for media. Supports specified image, PDF, audio, and video conversions. Does not implement OCR, PDF-to-DOCX, cropping, or cancellation. Do not call it a general cross-platform web converter. |
| Voxlink | [README](https://github.com/mrduhlol/Voxlink#readme) | Android microphone streaming to Linux over local Wi-Fi; Kotlin sender, Rust receiver, Tauri desktop app. The desktop app exposes a PipeWire/PulseAudio virtual microphone; the standalone receiver writes WAV. It is a prototype for trusted networks with no encryption or authentication; avoid calling the transport secure or promising zero latency. |
| github-widgets | [README](https://github.com/mrduhlol/github-widget#readme), [Android build file](https://github.com/mrduhlol/github-widget/blob/main/app/build.gradle.kts) | Android contribution widgets, appearance customization, statistics, shareable year image, cached graph. Kotlin and Jetpack Compose confirmed by build configuration. Username-based setup; do not imply the product is a JavaScript widget library. The README calls it GH-widgets, but portfolio uses the user's supplied github-widgets name. |
| Inkora | [README](https://github.com/mrduhlol/Inkora#readme) | Native Android notebook with rich text, handwriting, to-do notes, colored pages, autosave and local storage. Kotlin, Compose, Room. No account or cloud synchronization claimed. |
| DocuType | [README](https://github.com/mrduhlol/DocuType#readme), [manifest](https://github.com/mrduhlol/DocuType/blob/main/manifest.json) | JavaScript browser extension for automatic insertion of supplied text in editable Google Docs documents. Variable pacing and pause/resume/stop/speed controls. It does not measure typing skill or verify authorship; avoid presenting it as either. Relies on Docs internals and may be affected by Google updates. |
| Stikr | [README](https://github.com/mrduhlol/stikr#readme) | Android photo-to-sticker editor with optional subject cutout, outlines, captions, PNG sharing, and WhatsApp packs. Kotlin, Compose, ML Kit. Static stickers only; auto cutout relies on a Google Play services model download. Do not imply all cutout functionality is available without that prerequisite. |
| Black Jack | [README](https://github.com/mrduhlol/black-jack#readme), [package](https://github.com/mrduhlol/black-jack/blob/main/package.json), [worker configuration](https://github.com/mrduhlol/black-jack/blob/main/wrangler.jsonc) | Browser multiplayer Blackjack with public/private tables, virtual chips, nickname entry, and Liar's Table. TypeScript, Cloudflare Workers / Durable Objects, WebSockets. The README advertises `https://black-jack.abhishek-a.in`; it is noted here as source evidence, but not activated as the portfolio destination pending the user's supplied subdomain list. |

No live app was exercised during this content review. Repository documentation describes intended shipped behavior; this review does not independently certify those applications' reliability or release availability.
